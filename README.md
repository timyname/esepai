# Esep.ai — AI-помощник финансового учета и аналитики

**Esep** (`esepai`) — сервис умного финансового учета и аналитики на базе искусственного интеллекта, разработанный для предпринимателей и селлеров.

## 🚀 Стек технологий

* **Frontend:** Next.js (React), TypeScript, Tailwind CSS
* **Backend & Database:** Node.js, Supabase (PostgreSQL)
* **AI Integration:** OpenAI API / LLM Integration
* **Deploy:** Vercel / Docker
